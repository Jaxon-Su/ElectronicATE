# ElectronicATE v0.1.0-alpha.1

Windows x64 預覽版，發布日期：2026-10-03。本版將程式碼整合至 main，GitHub 僅保留 main 分支。

## 更新內容

- Page1 新增 DC Source1、DC Source2、DC Source3 各自的儀器與通訊設定。
- Page2 提供三個 DC Source 分頁，統一表格樣式，保存各台 Vin、I Limit 與條件列。
- Page3 在 Relay 下方提供三個 DC Input 分頁，連動 Page2 條件；左欄支援捲動。
- XML 保存／載入包含三台 DC Source 條件、Page2／Page3 分頁及 Page3 各台選取狀態。舊單台 DCSource 對應至 DC Source1，新增來源預設停用。
- 新增 All WFM：依示波器啟用通道各自保存 WFM，回報成功與失敗通道。
- Capture 按鈕改為三列：PNG、CSV／AllCSV、WFM／AllWFM，統一按鈕尺寸與字型。
- 調整主視窗高度與 Page1 通道欄寬。

## 驗證與限制

- 26 項離線 CTest 通過，包含三台 DC XML 往返、舊版相容、Page2 UI 同步及 Page3 選取還原測試。
- Qt 6.12.0、MinGW GCC 13.1.0、C++17 Windows x64 Release 建置。
- DC Source SCPI 驅動尚未實作，Page3 DC ON／change 按鈕維持停用；載入 XML 不會開啟電源。
- 未進行實體儀器驗證；All WFM 支援程度取決於示波器型號與既有 WFM 驅動。

## 使用方式

解壓縮 ElectronicATE-v0.1.0-alpha.1-win64.zip，執行 ElectronicATE.exe。
套件包含 Qt、MinGW 執行階段與 XML 設定；需另行安裝相容的 64 位元 NI-VISA 執行階段（VISA64.dll），套件不包含 NI-VISA 或儀器驅動。
更新前請備份原有設定。SHA256SUMS.txt 提供套件校驗值。
