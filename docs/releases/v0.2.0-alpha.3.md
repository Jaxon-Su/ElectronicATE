# ElectronicATE v0.2.0-alpha.3

此版本整合架構重構，提供 Windows x64 預覽套件。

## 主要變更

- Page1／Page2／Page3 的可測試核心模組與硬體工廠分離。
- Page1 設定完整寫入後再通知；處理重入載入及頁面關閉。
- Page2 表格一次提交條件快照，Page3 使用完整快照；補上無視窗表格測試。
- Page3 手動操作依序執行，擷取與未接手的示波器連線有明確釋放流程。
- Page4 統一通訊交換結果、逾時計算與例外處理。
- XML 預先驗證、Page2／Page3 失敗載入隔離及二進位檔案原子寫入。
- AC Source／Load／Relay 統一優先使用有效的結構化通訊地址。

## 驗證

- 24 組 CTest 測試通過，包含 offscreen QtWidgets 測試。
- 使用 Qt 6.12.0、MinGW GCC 13.1.0 建置 Windows x64 Release。
- 未進行實體儀器測試。

## 安裝

解壓縮 win64.zip，執行 ElectronicATE.exe。套件包含 Qt 與 MinGW 執行階段及 XML 設定。
使用 VISA 儀器需另行安裝相容的 64 位元 NI-VISA 執行階段與儀器驅動；本套件不包含這些驅動。
覆蓋舊版本前請自行備份既有設定。SHA256SUMS.txt 可用來驗證下載檔案。

## 已知限制

- Page3 佇列尚未涵蓋 Page4／Page5 或所有實體資源的跨頁互斥。
- Page4 仍使用同步通訊輪詢，阻塞中的驅動呼叫不能取消。
- 跨頁完整交易式設定套用與較嚴格的領域驗證仍待完成。
- 實機重連、關閉與驅動執行緒相容性尚待驗證。

此版本由 refactor/architecture-alpha3 分支發布，保留 main 作為原先基準。
